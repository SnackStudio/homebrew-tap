# Snack Studio Homebrew tap

```bash
brew install --cask snackstudio/tap/peel
```

| Cask | App |
| --- | --- |
| `peel` | [Peel](https://filesunwrapped.com): a free Mac unarchiver that opens ZIP, RAR, 7z and TAR archives like folders in Finder |
